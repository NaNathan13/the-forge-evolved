# Lessons — hard-won facts about THIS codebase

Append-only, capped, one line per lesson. Fed to fresh `forge-builder` / `forge-reviewer` subagents at dispatch
so they don't re-discover the same walls (D13). Distinct from inscribe's doc-writing.

**HIGH BAR to add:** only a *reusable* fact earned by overcoming a *real* wall — never a restatement of the
obvious or a one-off. Usually a forge run adds nothing here.

**Format:** `- <one-line fact>` (optionally area-tagged, e.g. `[auth] tokens refresh on 401, not on expiry`).
One line each.

**Soft cap: ~50 lines.** When it grows past that, prune the stalest / least-useful lines rather than letting it
bloat — a fed lessons file that's too long defeats its purpose.
